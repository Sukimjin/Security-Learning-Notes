# DVWA 靶场环境部署文档

> 实训环境：Kali Linux 2023.4（VMware 虚拟机）
> 部署目标：在本地搭建 LAMP + DVWA 漏洞演练平台，覆盖 4 个安全等级（Low / Medium / High / Impossible）

---

## 一、环境说明

| 组件 | 版本 | 作用 |
|---|---|---|
| 操作系统 | Kali Linux 2023.4 | 渗透测试环境 |
| Apache | 2.4.58 | Web 服务器 |
| MySQL | 5.x / 8.x | 数据库 |
| PHP | 8.x | 服务端脚本 |
| DVWA | 1.10（master 分支） | 漏洞演练平台 |

---

## 二、部署步骤

### 2.1 安装 LAMP 环境（Kali）

```bash
# 1. 更新软件源
sudo apt update && sudo apt upgrade -y

# 2. 安装 Apache、MySQL、PHP
sudo apt install -y apache2 mariadb-server php php-mysqli php-gd libapache2-mod-php

# 3. 启动服务并设置开机自启
sudo systemctl start apache2
sudo systemctl enable apache2
sudo systemctl start mariadb
sudo systemctl enable mariadb

# 4. 验证安装
apache2 -v
mysql --version
php -v
```

### 2.2 配置 MySQL 数据库

```bash
# 启动 MySQL 安全配置向导
sudo mysql_secure_installation

# 创建 DVWA 数据库与账号
sudo mysql -u root -p
```

```sql
CREATE DATABASE dvwa;
CREATE USER 'dvwa'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON dvwa.* TO 'dvwa'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

### 2.3 下载与部署 DVWA

```bash
# 1. 下载 DVWA（建议下载 master 分支获得最新版本）
cd /var/www/html/
sudo git clone https://github.com/digininja/DVWA.git dvwa

# 2. 配置 DVWA 配置文件
cd dvwa/config/
sudo cp config.inc.php.dist config.inc.php
sudo nano config.inc.php
```

修改以下字段：
```php
$_DVWA['db_server']   = '127.0.0.1';
$_DVWA['db_database'] = 'dvwa';
$_DVWA['db_user']     = 'dvwa';
$_DVWA['db_password'] = 'password';
$_DVWA['recaptcha_public_key']  = '';
$_DVWA['recaptcha_private_key'] = '';
```

### 2.4 设置文件权限

```bash
# 给 DVWA 目录可写权限（用于上传文件、写入日志等）
sudo chown -R www-data:www-data /var/www/html/dvwa/
sudo chmod -R 755 /var/www/html/dvwa/
```

### 2.5 配置 PHP 参数

```bash
# 编辑 PHP 配置，允许远程文件包含等（实训需要）
sudo nano /etc/php/8.2/apache2/php.ini
```

修改以下字段（生产环境勿用）：
```ini
allow_url_include = On
allow_url_fopen = On
display_errors = On
```

### 2.6 重启服务并初始化

```bash
sudo systemctl restart apache2
```

浏览器访问 `http://127.0.0.1/dvwa/setup.php`：

1. 页面会显示环境检查状态，确保所有项为绿色
2. 点击底部 **Create / Reset Database** 按钮
3. 自动跳转至登录页，默认账号：`admin` / `password`

### 2.7 设置安全等级

登录后 → 左侧菜单 **DVWA Security** → 选择难度：
- Low（无防护）
- Medium（基础过滤）
- High（强化防护）
- Impossible（安全编码）

不同等级对应不同的漏洞复现难度，建议按 Low → Medium → High → Impossible 顺序练习。

## 三、常见问题排查

| 问题 | 排查方向 |
|---|---|
| 访问 setup.php 提示红色错误 | PHP 扩展未安装（mysqli / gd） |
| 数据库连接失败 | config.inc.php 数据库账号密码错误 |
| 上传目录无法写入 | `chown -R www-data:www-data` |
| reCAPTCHA 警告 | 留空即可，不影响核心功能 |

---

## 四、实训注意事项

1. **DVWA 仅限本地或隔离靶机部署**，切勿将 DVWA 部署在公网服务器
2. 每次复现完漏洞，及时将安全等级调回 Impossible，避免遗忘导致风险
3. 截图保存靶场界面时，**注意遮挡真实 IP / MAC 等敏感信息**
4. 复现 SQL 注入等破坏性漏洞时，建议在数据库层做快照，避免数据丢失
5. 实训结束后，可在 `08-系统加固方案` 中查看完整的环境清理步骤
