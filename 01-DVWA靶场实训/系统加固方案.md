# DVWA 靶场系统加固方案（8 套）

> 本文档基于 DVWA 靶场环境（LAMP 架构）编写，提供 8 套系统加固方案，覆盖 Web 服务、数据库、操作系统、网络访问控制等层面。
> 实训完成后，建议执行全部加固方案以确保环境清理彻底。

| 编号 | 方案名称 | 目标 |

| ① | Apache 配置加固 | Web 服务器安全配置 |

## ① Apache 配置加固

### 1.1 隐藏版本信息

```apache
# /etc/apache2/apache2.conf 或 /etc/apache2/conf-enabled/security.conf
ServerTokens Prod
ServerSignature Off
```

**效果**：HTTP 响应头不再暴露 Apache 版本、模块版本、PHP 版本。

### 1.2 禁用危险 HTTP 方法

```apache
# /etc/apache2/conf-enabled/security.conf
<Location "/">
    <LimitExcept GET POST>
        Require all denied
    </LimitExcept>
</Location>
```

**效果**：禁止 PUT、DELETE、OPTIONS、TRACE 等非常用方法。

### 1.3 禁用目录列表

```apache
# /etc/apache2/apache2.conf
<Directory /var/www/>
    Options -Indexes
    AllowOverride None
    Require all granted
</Directory>
```

**效果**：访问目录时不会列出文件列表。

### 1.4 限制请求体大小

```apache
# 防止大文件上传 DoS
LimitRequestBody 10485760  # 10MB
```

### 1.5 配置安全 HTTP 响应头

```apache
# /etc/apache2/conf-enabled/security-headers.conf
<IfModule mod_headers.c>
    Header always set X-Content-Type-Options "nosniff"
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set X-XSS-Protection "1; mode=block"
    Header always set Referrer-Policy "strict-origin-when-cross-origin"
    Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
    Header always set Content-Security-Policy "default-src 'self'"
</IfModule>
```

### 1.6 启用 HTTPS（生产环境必须）

```bash
# 1. 启用 SSL 模块
sudo a2enmod ssl
sudo a2ensite default-ssl

# 2. 配置 HTTPS 重定向
sudo nano /etc/apache2/sites-available/000-default.conf
# 添加：Redirect permanent / https://yourdomain.com/
```

### 1.7 限速与并发控制

```apache
# 安装 mod_evasive（防 DDoS）
sudo apt install libapache2-mod-evasive
sudo nano /etc/apache2/mods-enabled/evasive.conf
```
```apache
<IfModule mod_evasive20.c>
    DOSHashTableSize 3097
    DOSPageCount 5
    DOSSiteCount 100
    DOSPageInterval 1
    DOSSiteInterval 1
    DOSBlockingPeriod 600
    DOSLogDir "/var/log/mod_evasive"
</IfModule>
```

### 1.8 验证 Apache 配置

```bash
# 检查配置语法
sudo apache2ctl configtest

# 重启服务
sudo systemctl restart apache2

# 验证响应头
curl -I http://127.0.0.1
```

## ② MySQL 安全配置

### 2.1 初始化安全配置

```bash
# 启动安全配置向导（首次部署必做）
sudo mysql_secure_installation

# 推荐回答：
# - 设置 root 密码：是
# - 移除匿名用户：是
# - 禁止 root 远程登录：是
# - 移除测试数据库：是
# - 立即刷新权限表：是
```

### 2.2 创建专用应用账号（最小权限原则）

```sql
-- 创建专用账号（不要使用 root）
CREATE USER 'dvwa_app'@'localhost' IDENTIFIED BY 'StrongPassword_2026!';

-- 仅授予必要的权限
GRANT SELECT, INSERT, UPDATE ON dvwa.* TO 'dvwa_app'@'localhost';

-- 禁止 FILE 权限（防止 LOAD_FILE/INTO OUTFILE 写文件）
REVOKE FILE ON *.* FROM 'dvwa_app'@'localhost';

-- 刷新权限
FLUSH PRIVILEGES;
```

### 2.3 修改监听地址

```ini
# /etc/mysql/mariadb.conf.d/50-server.cnf
[mysqld]
bind-address = 127.0.0.1    # 仅本机访问，禁止远程
# 或
skip-networking              # 完全禁用 TCP 监听（仅 Unix Socket）
```

```bash
sudo systemctl restart mariadb
```

### 2.4 启用日志审计

```ini
# /etc/mysql/mariadb.conf.d/50-server.cnf
[mysqld]
general_log = 1
general_log_file = /var/log/mysql/mysql.log
log_error = /var/log/mysql/error.log
slow_query_log = 1
slow_query_log_file = /var/log/mysql/slow.log
long_query_time = 2
```

```bash
sudo mkdir -p /var/log/mysql
sudo chown mysql:mysql /var/log/mysql
sudo systemctl restart mariadb
```

### 2.5 密码策略

```sql
-- 安装 validate_password 插件
INSTALL PLUGIN validate_password SONAME 'validate_password.so';

-- 设置密码策略
SET GLOBAL validate_password_policy = STRONG;
SET GLOBAL validate_password_length = 12;
```

### 2.6 验证 MySQL 安全

```bash
# 尝试以 root 远程登录（应失败）
mysql -h 0.0.0.0 -u root -p

# 查看用户列表
mysql -u root -p -e "SELECT User, Host FROM mysql.user;"

# 查看权限
mysql -u root -p -e "SHOW GRANTS FOR 'dvwa_app'@'localhost';"
```

## ③ PHP 安全配置

### 3.1 关键配置（php.ini）

```ini
# /etc/php/8.2/apache2/php.ini

# 关闭远程文件包含（防止 RFI）
allow_url_include = Off
allow_url_fopen = Off

# 关闭错误显示（生产环境）
display_errors = Off
display_startup_errors = Off
log_errors = On
error_log = /var/log/php/error.log

# 关闭危险函数（生产环境）
disable_functions = exec,passthru,shell_exec,system,proc_open,popen,curl_exec,curl_multi_exec,parse_ini_file,show_source
# 注：DVWA 训练时需放开 disable_functions

# 限制文件上传
file_uploads = On
upload_max_filesize = 10M
post_max_size = 10M
max_file_uploads = 5

# 限制脚本执行时间（防 DoS）
max_execution_time = 30
max_input_time = 30
memory_limit = 128M

# 隐藏 PHP 版本
expose_php = Off

# 限制访问路径
open_basedir = /var/www/html:/tmp
```

### 3.2 会话安全

```ini
# php.ini
session.cookie_httponly = 1
session.cookie_secure = 1
session.cookie_samesite = "Lax"
session.use_strict_mode = 1
session.gc_maxlifetime = 1800
```

### 3.3 文件上传目录限制

```php
# 在上传目录创建 .htaccess 禁止 PHP 执行
# /var/www/html/dvwa/hackable/uploads/.htaccess
php_flag engine off
<FilesMatch "\.(php|php3|php4|php5|phtml|pl|py|jsp|asp|sh|cgi)$">
    Deny from all
</FilesMatch>
```

### 3.4 验证 PHP 配置

```bash
# 创建测试文件
sudo bash -c 'echo "<?php phpinfo(); ?>" > /var/www/html/info.php'

# 浏览器访问，验证：
# - allow_url_include = Off
# - disable_functions 已配置
# - expose_php = Off

# 测试完成后立即删除
sudo rm /var/www/html/info.php
```

## ④ Linux 系统加固

### 4.1 账号安全

```bash
# 1. 锁定无用账号
sudo passwd -l games
sudo passwd -l news
sudo passwd -l lp

# 2. 设置密码策略（/etc/login.defs）
PASS_MAX_DAYS   90
PASS_MIN_DAYS   7
PASS_MIN_LEN    12
PASS_WARN_AGE   14

# 3. 强制下次登录修改密码
sudochage -d 0 username
```

### 4.2 禁用 root SSH 登录

```bash
sudo nano /etc/ssh/sshd_config
```
```sshd_config
PermitRootLogin no
PasswordAuthentication no    # 启用密钥登录
PubkeyAuthentication yes
Port 2222                     # 修改默认端口
AllowUsers your_admin
```
```bash
sudo systemctl restart sshd
```

### 4.3 防火墙配置（iptables / ufw）

```bash
# 使用 ufw（Ubuntu 简单方案）
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw allow 80/tcp      # HTTP
sudo ufw allow 443/tcp     # HTTPS
sudo ufw allow 2222/tcp    # SSH（修改后的端口）
sudo ufw enable

# 查看状态
sudo ufw status verbose
```

### 4.4 文件权限加固

```bash
# 关键文件权限
sudo chmod 600 /etc/shadow /etc/gshadow
sudo chmod 644 /etc/passwd /etc/group

# Web 目录权限
sudo chown -R root:root /var/www/html/
sudo find /var/www/html/ -type d -exec chmod 755 {} \;
sudo find /var/www/html/ -type f -exec chmod 644 {} \;

# 上传目录仅 www-data 可写
sudo chown -R www-data:www-data /var/www/html/dvwa/hackable/uploads/
sudo chmod 755 /var/www/html/dvwa/hackable/uploads/
```

### 4.5 内核参数加固

```bash
sudo nano /etc/sysctl.conf
```
```sysctl
# IP 转发关闭（如非路由器）
net.ipv4.ip_forward = 0

# SYN Cookie 防 SYN Flood
net.ipv4.tcp_syncookies = 1

# 忽略 ICMP 重定向
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.default.accept_redirects = 0
net.ipv4.conf.all.secure_redirects = 0
net.ipv4.conf.default.secure_redirects = 0

# 忽略源路由
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.default.accept_source_route = 0

# 记录可疑包
net.ipv4.conf.all.log_martians = 1

# 忽略广播 ping
net.ipv4.icmp_echo_ignore_broadcasts = 1
```
```bash
sudo sysctl -p
```

### 4.6 安装 fail2ban 防暴力破解

```bash
sudo apt install fail2ban

sudo nano /etc/fail2ban/jail.local
```
```ini
[DEFAULT]
bantime = 600
findtime = 600
maxretry = 5

[sshd]
enabled = true
port = 2222
filter = sshd
logpath = /var/log/auth.log

[apache-auth]
enabled = true
port = http,https
filter = apache-auth
logpath = /var/log/apache2/*error.log
```
```bash
sudo systemctl enable fail2ban
sudo systemctl start fail2ban
```

### 4.7 AIDE 文件完整性检查

```bash
sudo apt install aide

# 初始化数据库
sudo aideinit

# 定期检查
sudo aide --check
```

```bash
# 配置文件（含数据库密码）
sudo chmod 640 /var/www/html/dvwa/config/config.inc.php

# 日志目录
sudo chmod 755 /var/log/apache2
sudo chmod 644 /var/log/apache2/*.log

# 数据库文件
sudo chmod 750 /var/lib/mysql
sudo chown -R mysql:mysql /var/lib/mysql
```

```apache
# /var/www/html/dvwa/hackable/uploads/.htaccess
php_flag engine off
<FilesMatch "\.(php|php3|php4|php5|p7|phtml|pl|py|jsp|asp|sh|cgi|aspx)$">
```

### 5.4 防目录穿越配置

```php

$file_name = basename($_GET['file']);  // 去除路径成分
```

## ⑥ 日志审计加固

### 6.1 Apache 日志配置

```apache
# /etc/apache2/apache2.conf
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\" %D" combined
CustomLog /var/log/apache2/access.log combined
ErrorLog /var/log/apache2/error.log
```

### 6.2 日志轮转

```bash
# /etc/logrotate.d/apache2
/var/log/apache2/*.log {
    daily
    missingok
    rotate 180          # 留存 180 天（等保 2.0 要求 6 个月）
    compress
    delaycompress
    notifempty
    create 0640 root adm
    sharedscripts
    postrotate
        systemctl reload apache2 > /dev/null 2>&1 || true
    endscript
}
```

## ⑦ 网络访问控制

### 7.1 防火墙规则（iptables 详细版）

```bash
# 清空默认规则
sudo iptables -F
sudo iptables -X

# 默认策略
sudo iptables -P INPUT DROP
sudo iptables -P FORWARD DROP
sudo iptables -P OUTPUT ACCEPT

# 允许 lo
sudo iptables -A INPUT -i lo -j ACCEPT

# 允许已建立的连接
sudo iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT

# 允许 SSH
sudo iptables -A INPUT -p tcp --dport 2222 -j ACCEPT

# 允许 HTTP/HTTPS
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT

# 拒绝 ICMP ping
sudo iptables -A INPUT -p icmp --icmp-type 8 -j DROP

# 保存规则
sudo netfilter-persistent save
```

### 7.2 限制 SSH 远程访问源 IP

```bash
# 仅允许特定 IP 段访问 SSH
sudo iptables -A INPUT -p tcp -s 192.168.1.0/24 --dport 2222 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 2222 -j DROP
```

### 7.3 数据库仅本地访问

```ini
# /etc/mysql/mariadb.conf.d/50-server.cnf
bind-address = 127.0.0.1
```

### 7.4 Web 目录访问限制

```apache
# 禁止访问敏感目录
<DirectoryMatch "(?i)(config|hackable|setup|tests)">
    Require all denied
</DirectoryMatch>
```

## ⑧ DVWA 环境清理

> ⚠️ 实训结束后**必须**执行此流程，避免靶场意外暴露。

### 8.1 销毁数据库

```bash
# 1. 备份（如需保留学习资料）
mysqldump -u root -p dvwa > dvwa_backup_$(date +%Y%m%d).sql

# 2. 销毁 DVWA 数据库
mysql -u root -p -e "DROP DATABASE IF EXISTS dvwa;"
mysql -u root -p -e "DROP USER 'dvwa'@'localhost';"
mysql -u root -p -e "DROP USER 'dvwa_app'@'localhost';"
```

### 8.2 清理 Web 目录

```bash
# 1. 备份 Web 目录（如需）
sudo tar -czf dvwa_web_$(date +%Y%m%d).tar.gz /var/www/html/dvwa/

# 2. 移除 DVWA
sudo rm -rf /var/www/html/dvwa/

# 3. 清理配置
sudo rm -f /etc/apache2/sites-enabled/dvwa*
```

### 8.3 清理日志

```bash
# 清理 Apache 残留日志
sudo rm -f /var/log/apache2/*dvwa*
sudo truncate -s 0 /var/log/apache2/access.log
sudo truncate -s 0 /var/log/apache2/error.log

# 清理 MySQL 残留
sudo rm -f /var/log/mysql/*
```

### 8.4 清理用户上传文件

```bash
# 清理上传目录
sudo rm -rf /var/www/html/dvwa/hackable/uploads/*
```

### 8.5 清理临时文件

```bash
# 清理 PHP 临时文件
sudo rm -rf /tmp/php*
sudo rm -rf /var/lib/php/sessions/*

# 清理 apt 缓存
sudo apt clean
```

### 8.6 恢复 PHP 默认配置

```bash
# 恢复 php.ini 默认值
sudo cp /etc/php/8.2/apache2/php.ini.orig /etc/php/8.2/apache2/php.ini
sudo systemctl restart apache2
```

### 8.7 创建虚拟机关机快照

```bash
# 在 VMware 中：
# 1. 关闭虚拟机
# 2. 右键 → Snapshot → Take Snapshot
# 3. 命名为 "DVWA-Cleaned-2026-XX-XX"
```

### 8.8 销毁整体靶场（如不再使用）

```bash
# 1. 停止服务
sudo systemctl stop apache2
sudo systemctl stop mariadb
sudo systemctl disable apache2
sudo systemctl disable mariadb

# 2. 卸载软件
sudo apt remove --purge apache2* mariadb-server* php*
sudo apt autoremove

# 3. 清理残留
sudo rm -rf /var/www/html/*
sudo rm -rf /etc/apache2 /etc/mysql /etc/php
```

## 加固验证清单

完成所有加固后，可通过以下方式验证：

### 9.1 Apache 加固验证
- [ ] `curl -I http://127.0.0.1` 不显示 Apache 版本
- [ ] `curl -X OPTIONS http://127.0.0.1` 返回 403
- [ ] `curl -X TRACE http://127.0.0.1` 返回 405
- [ ] HTTP 响应头包含 X-Content-Type-Options 等安全头
- [ ] 访问目录不显示文件列表

### 9.2 MySQL 加固验证
- [ ] `mysql -h 0.0.0.0 -u root -p` 远程登录失败
- [ ] 普通账号权限最小化（仅 `SELECT/INSERT/UPDATE`）
- [ ] `general_log` 与 `slow_query_log` 正常记录

### 9.3 PHP 加固验证
- [ ] `phpinfo()` 显示 `allow_url_include = Off`
- [ ] `disable_functions` 列表生效
- [ ] 上传目录下的 .php 文件无法执行（403）
- [ ] Session Cookie 含 `HttpOnly` + `SameSite`

### 9.4 Linux 加固验证
- [ ] `sudo passwd -l root` 后无法切换
- [ ] `ssh root@server` 失败
- [ ] `ufw status` 显示规则生效
- [ ] `fail2ban-client status sshd` 正常

### 9.5 网络访问控制验证
- [ ] 外部 IP 无法访问 22/3306 等端口
- [ ] 非白名单 IP 无法访问 SSH
- [ ] ICMP ping 不通

## 总结

完成全部 8 套加固方案后，DVWA 靶场环境将达到：

| 维度 | 加固前 | 加固后 |
|---|---|---|
| 信息泄露 | 暴露版本/目录 | 最小化披露 |
| 暴力破解 | 无防护 | fail2ban + 防火墙 |
| SQL 注入 | DVWA 故意漏洞 | 修复 + WAF（生产） |
| 文件上传 | DVWA 故意漏洞 | 上传目录禁执行 |
| 数据泄露 | root 远程可登 | 本地账号 + 最小权限 |
| 日志审计 | 默认配置 | 完整留存 + 告警 |
| 网络暴露 | 全端口开放 | 最小化白名单 |
| 残留风险 | 靶场永久存在 | 完整清理流程 |

> **本加固方案基于 DVWA 1.10 编写，生产环境加固需结合实际业务调整。**
