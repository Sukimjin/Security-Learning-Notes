# DVWA 靶场日志审计分析

> 实训环境：DVWA（Kali Linux 2023.4 + LAMP）
> 分析对象：Apache 访问日志（access.log）、错误日志（error.log）
> 分析时间窗：DVWA 部署以来的攻击演练日志

---

## 一、Apache 日志基础

### 1.1 访问日志格式

Apache 默认 combined 格式：
```
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\"" combined
```

**字段说明**：
| 字段 | 含义 |
|---|---|
| `%h` | 客户端 IP |
| `%l` | 客户端 identd |
| `%u` | HTTP 认证用户 |
| `%t` | 请求时间 |
| `%r` | 请求行（方法 + URL + 协议） |
| `%>s` | 响应状态码 |
| `%b` | 响应字节数 |
| `Referer` | 引用页 |
| `User-Agent` | 客户端标识 |

### 1.2 日志位置

| 类型 | 路径（Kali/Debian） |
|---|---|
| 访问日志 | `/var/log/apache2/access.log` |
| 错误日志 | `/var/log/apache2/error.log` |
| 其他访问日志 | `/var/log/apache2/other_vhosts_access.log` |

## 二、异常日志梳理（20+ 条典型模式）

本节整理在 DVWA 实训过程中产生的**典型异常访问模式**，可用于安全运营中的日志告警规则。

### 2.1 漏洞扫描特征

#### ① 目录爆破
```log
192.168.1.100 - - [10/Aug/2026:14:23:01 +0800] "GET /admin HTTP/1.1" 404 209
192.168.1.100 - - [10/Aug/2026:14:23:01 +0800] "GET /backup HTTP/1.1" 404 209
192.168.1.100 - - [10/Aug/2026:14:23:01 +0800] "GET /config.php HTTP/1.1" 404 209
192.168.1.100 - - [10/Aug/2026:14:23:01 +0800] "GET /phpmyadmin HTTP/1.1" 404 209
192.168.1.100 - - [10/Aug/2026:14:23:02 +0800] "GET /setup.php HTTP/1.1" 200 1234
192.168.1.100 - - [10/Aug/2026:14:23:02 +0800] "GET /test HTTP/1.1" 404 209
192.168.1.100 - - [10/Aug/2026:14:23:02 +0800] "GET /wp-admin HTTP/1.1" 404 209
```
**特征**：短时间内大量 404，请求 URL 为常见敏感路径。
**告警规则**：同 IP 1 分钟内 404 超过 10 次。

#### ② Nmap 端口扫描
```log
192.168.1.100 - - [10/Aug/2026:14:30:00 +0800] "GET / HTTP/1.1" 200 1234
192.168.1.100 - - [10/Aug/2026:14:30:00 +0800] "GET / HTTP/1.1" 200 1234
192.168.1.100 - - [10/Aug/2026:14:30:00 +0800] "GET / HTTP/1.1" 200 1234
```
**特征**：大量连接，User-Agent 含 `nmap` / `masscan`。
**告警规则**：User-Agent 包含扫描工具关键字。

#### ③ Xray 自动化扫描
```log
192.168.1.100 - - [10/Aug/2026:15:01:00 +0800] "GET /dvwa/vulnerabilities/sqli/?id=1%27%20OR%201%3D1-- HTTP/1.1" 200 4567
192.168.1.100 - - [10/Aug/2026:15:01:01 +0800] "GET /dvwa/vulnerabilities/xss_r/?name=%3Cscript%3Ealert%281%29%3C%2Fscript%3E HTTP/1.1" 200 3456
```
**特征**：URL 含 URL 编码的 SQL 注入 / XSS Payload。
**告警规则**：URL 包含 `union select`、`<script>`、`../` 等关键字。

### 2.2 暴力破解特征

#### ④ 短时间高频登录失败
```log
192.168.1.100 - - [10/Aug/2026:16:00:01 +0800] "POST /dvwa/login.php HTTP/1.1" 200 4837
192.168.1.100 - - [10/Aug/2026:16:00:03 +0800] "POST /dvwa/login.php HTTP/1.1" 200 4837
192.168.1.100 - - [10/Aug/2026:16:00:05 +0800] "POST /dvwa/login.php HTTP/1.1" 200 4837
192.168.1.100 - - [10/Aug/2026:16:00:07 +0800] "POST /dvwa/login.php HTTP/1.1" 200 4837
192.168.1.100 - - [10/Aug/2026:16:00:09 +0800] "POST /dvwa/login.php HTTP/1.1" 200 4880
```
**特征**：同一 URL 短时间内高频访问，最后一次响应长度（4880）与其他（4837）不同 → 成功爆破。
**告警规则**：单 IP 1 分钟内 `login.php` 失败超过 5 次触发临时封禁。

### 2.3 SQL 注入特征

#### ⑤ 单引号报错探测
```log
192.168.1.100 - - [10/Aug/2026:16:30:00 +0800] "GET /dvwa/vulnerabilities/sqli/?id=1%27 HTTP/1.1" 500 1234
```
**特征**：URL 含单引号且返回 500。
**告警规则**：URL 含 `%27`（单引号 URL 编码）且状态码 500。

#### ⑥ 联合查询注入
```log
192.168.1.100 - - [10/Aug/2026:16:31:00 +0800] "GET /dvwa/vulnerabilities/sqli/?id=1%27%20UNION%20SELECT%201%2Cdatabase%28%29-- HTTP/1.1" 200 4567
```
**特征**：URL 包含 `UNION SELECT`、`database()` 等 SQL 关键字。
**告警规则**：URL 包含 SQL 关键字且非业务参数。

#### ⑦ 布尔盲注探测
```log
192.168.1.100 - - [10/Aug/2026:16:32:00 +0800] "GET /dvwa/vulnerabilities/sqli/?id=1%27%20AND%20substring%28database%28%29%2C1%2C1%29%3D%27d%27-- HTTP/1.1" 200 4567
```
**特征**：URL 含 `AND substring()`、`MID()`、`ASCII()` 等函数。
**告警规则**：URL 含 `substring(`、`ascii(` 等函数调用。

### 2.4 XSS 特征

#### ⑧ 反射型 XSS
```log
192.168.1.100 - - [10/Aug/2026:17:00:00 +0800] "GET /dvwa/vulnerabilities/xss_r/?name=%3Cscript%3Ealert%281%29%3C%2Fscript%3E HTTP/1.1" 200 4567
```
**特征**：URL 含 `<script>` 标签。
**告警规则**：URL 包含 `<script>`、`onerror=`、`onload=`。

#### ⑨ 存储型 XSS
```log
192.168.1.100 - - [10/Aug/2026:17:05:00 +0800] "POST /dvwa/vulnerabilities/xss_s/ HTTP/1.1" 200 1234 "txName=<script>alert(1)</script>"
```
**特征**：POST 表单含 XSS Payload，后续 GET 触发。
**告警规则**：POST 数据含 HTML 标签。

### 2.5 文件上传 / 命令注入特征

#### ⑩ PHP 文件上传
```log
192.168.1.100 - - [10/Aug/2026:17:30:00 +0800] "POST /dvwa/vulnerabilities/upload/ HTTP/1.1" 200 1234 "Content-Disposition: form-data; name=\"uploaded\"; filename=\"shell.php\""
```
**特征**：上传文件名含 `.php`、`.jsp`、`.aspx` 等可执行扩展名。
**告警规则**：上传文件含可执行扩展名。

#### ⑪ 命令注入
```log
192.168.1.100 - - [10/Aug/2026:17:35:00 +0800] "GET /dvwa/vulnerabilities/exec/?ip=127.0.0.1%3B%20ls HTTP/1.1" 200 5678
```
**特征**：URL 含 `;`、`|`、`&&` 等 shell 操作符。
**告警规则**：URL 含 shell 元字符。

### 2.6 异常访问模式

#### ⑫ User-Agent 异常
```log
192.168.1.100 - - [10/Aug/2026:18:00:00 +0800] "GET / HTTP/1.1" 200 1234 "User-Agent: sqlmap/1.5.2"
192.168.1.100 - - [10/Aug/2026:18:00:01 +0800] "GET / HTTP/1.1" 200 1234 "User-Agent: Mozilla/5.0 (compatible; Nmap Scripting Engine)"
```
**特征**：User-Agent 包含工具名称。
**告警规则**：User-Agent 含 `sqlmap`、`nmap`、`nikto`、`dirbuster`、`burp`、`xray`。

#### ⑬ Referer 异常
```log
192.168.1.100 - - [10/Aug/2026:18:10:00 +0800] "GET /admin HTTP/1.1" 200 1234 "Referer: http://attacker.com/evil.html"
```
**特征**：Referer 来自外网恶意域名。
**告警规则**：Referer 来自黑名单域名。

#### ⑭ 非工作时间访问
```log
192.168.1.100 - - [10/Aug/2026:03:00:00 +0800] "GET /admin HTTP/1.1" 200 1234
```
**特征**：凌晨 3 点管理后台访问。
**告警规则**：非工作时间（0:00-6:00）管理后台访问。

#### ⑮ 异常 HTTP 方法
```log
192.168.1.100 - - [10/Aug/2026:18:20:00 +0800] "OPTIONS / HTTP/1.1" 200 -
192.168.1.100 - - [10/Aug/2026:18:20:01 +0800] "PUT /test.txt HTTP/1.1" 403 209
192.168.1.100 - - [10/Aug/2026:18:20:02 +0800] "DELETE /admin HTTP/1.1" 403 209
```
**特征**：出现 OPTIONS / PUT / DELETE 等非常用方法。
**告警规则**：非常用 HTTP 方法访问。

#### ⑯ 异常大请求体
```log
192.168.1.100 - - [10/Aug/2026:18:30:00 +0800] "POST /upload HTTP/1.1" 200 1234 "Content-Length: 104857600"
```
**特征**：POST 请求体超大（100MB）。
**告警规则**：请求体超过 10MB。

#### ⑰ Cookie 异常
```log
192.168.1.100 - - [10/Aug/2026:18:40:00 +0800] "GET / HTTP/1.1" 200 1234 "Cookie: PHPSESSID=../../../etc/passwd"
```
**特征**：Cookie 含路径穿越字符。
**告警规则**：Cookie 含 `../`、特殊控制字符。

#### ⑱ 短时间大量 500 错误
```log
192.168.1.100 - - [10/Aug/2026:18:50:00 +0800] "GET /api?id=1' HTTP/1.1" 500 1234
192.168.1.100 - - [10/Aug/2026:18:50:01 +0800] "GET /api?id=1' HTTP/1.1" 500 1234
192.168.1.100 - - [10/Aug/2026:18:50:02 +0800] "GET /api?id=1' HTTP/1.1" 500 1234
```
**特征**：连续 500 错误，可能是 SQL 注入探测。
**告警规则**：单 IP 1 分钟内 500 错误超过 3 次。

#### ⑲ 异常 URL 长度
```log
192.168.1.100 - - [10/Aug/2026:19:00:00 +0800] "GET /search?q=AAAA...5000字符...AAAA HTTP/1.1" 414 209
```
**特征**：URL 长度超过正常范围。
**告警规则**：URL 长度超过 2048 字符。

#### ⑳ 跨域 CORS 探测
```log
192.168.1.100 - - [10/Aug/2026:19:10:00 +0800] "OPTIONS /api/users HTTP/1.1" 200 - "Origin: http://evil.com"
```
**特征**：OPTIONS 请求携带恶意 Origin。
**告警规则**：CORS 探测但服务端配置 `*` 通配。

#### ㉑ Webshell 访问特征
```log
192.168.1.100 - - [10/Aug/2026:19:20:00 +0800] "POST /uploads/shell.php HTTP/1.1" 200 1234
192.168.1.100 - - [10/Aug/2026:19:20:01 +0800] "GET /uploads/shell.php?cmd=whoami HTTP/1.1" 200 56
```
**特征**：访问上传目录下的 .php 文件且携带 cmd 参数。
**告警规则**：上传目录下的 .php 访问。

#### ㉒ 代理转发特征
```log
192.168.1.100 - - [10/Aug/2026:19:30:00 +0800] "GET /admin HTTP/1.1" 200 1234 "X-Forwarded-For: 1.2.3.4"
```
**特征**：请求携带 X-Forwarded-For，尝试伪造 IP。
**告警规则**：X-Forwarded-For 与真实 IP 不一致。

## 三、自动化日志分析命令

### 3.1 统计高频访问 IP

```bash
awk '{print $1}' /var/log/apache2/access.log | sort | uniq -c | sort -rn | head 20
```

### 3.2 统计高频访问 URL

```bash
awk '{print $7}' /var/log/apache2/access.log | sort | uniq -c | sort -rn | head 20
```

### 3.3 统计 4xx/5xx 错误

```bash
awk '{print $9}' /var/log/apache2/access.log | grep -E "^(4|5)" | sort | uniq -c | sort -rn
```

### 3.4 查找 SQL 注入尝试

```bash
grep -iE "union.*select|concat.*char|benchmark|sleep\(|extractvalue" /var/log/apache2/access.log
```

### 3.5 查找 XSS 尝试

```bash
grep -iE "<script|onerror=|onload=|javascript:" /var/log/apache2/access.log
```

### 3.6 查找 Webshell 访问

```bash
grep -E "\.(php|jsp|aspx).*cmd=|eval\(|base64_decode" /var/log/apache2/access.log
```

## 五、日志审计工作建议

### 5.1 日常巡检（每日）
- 统计访问量 Top 10 IP
- 统计错误状态码占比
- 重点路径（/admin、/login）访问情况

### 5.2 周度审计（每周）
- 全量异常日志梳理
- 攻击特征（OWASP Top 10）匹配
- IP 黑名单更新

### 5.3 月度审计（每月）
- 攻击趋势分析
- 告警规则优化
- 应急响应演练

### 5.4 日志留存要求
- **等保 2.0 要求**：网络日志留存不少于 6 个月
- 重要系统建议留存 1 年以上
- 日志完整性保护（防篡改）
