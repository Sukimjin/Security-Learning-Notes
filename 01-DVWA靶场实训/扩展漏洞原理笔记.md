# 扩展漏洞原理笔记（SSRF / XXE / 反序列化 / 越权与逻辑漏洞）

> 这篇记录 DVWA 靶场之外的常见 Web 漏洞（SSRF / XXE / 反序列化 / 越权与逻辑漏洞）。DVWA 本身没内置这些，所以只讲原理、危害、检测与防御，不提供可利用的 Payload 或攻击脚本，用于理解攻击面、做好防御。

---

## 一、SSRF（服务端请求伪造，Server-Side Request Forgery）

**OWASP 对应**：OWASP Top 10 (2021) A10。

**原理**：应用在服务端发起请求时（如抓取 URL、加载远程图片、调用内部接口），未对目标地址做校验，攻击者篡改目标 URL 后，让服务器去访问**本不该访问的内部地址**（内网服务、云元数据接口等）。

**典型危害场景**：
- 读取云环境元数据（如 `http://169.254.169.254`）
- 探测内网存活主机与开放端口
- 读取本地文件（`file://` 协议）
- 绕过防火墙 / ACL，以内网身份访问内部系统

**检测与防御**：
- URL **白名单**：只允许访问受信任的域名 / IP 段
- 禁用不需要的协议（只允许 http/https，禁用 file、gopher、dict 等）
- 解析域名后**再次校验 IP** 是否落在内网段（防 DNS 重绑定）
- 出站网络隔离：限制服务器可访问的网段
- 请求侧做超时与响应体大小限制，避免被用作端口扫描器

## 二、XXE（XML 外部实体注入，XML External Entity）

**OWASP 对应**：OWASP Top 10 (2017) A4（2021 版并入 A05 安全配置错误）。

**原理**：XML 解析器支持**外部实体**引用，当应用解析用户可控的 XML 且未禁用外部实体时，攻击者可利用实体声明读取本地文件、发起 SSRF 请求，甚至造成拒绝服务（十亿笑攻击）。

**典型危害场景**：
- 读取服务器本地文件（`file:///etc/passwd` 等）
- 发起内网请求（与 SSRF 结合）
- 资源耗尽（实体递归展开导致 DoS）

**检测与防御**：
- **禁用外部实体**：解析库关闭 DTD / 外部实体加载
- 使用安全的 JSON 替代 XML（业务允许时）
- 校验 XML 内容、限制解析大小与深度
- 更新解析器组件，避免已知 CVE

## 三、反序列化漏洞

**OWASP 对应**：OWASP Top 10 (2017) A8（2021 版并入 A08 软件与数据完整性失败）。

**原理**：把字节流还原为对象的「反序列化」过程，若数据**来源不可信**且被直接反序列化，攻击者可构造恶意对象触发任意代码执行或数据篡改。常见于 Java（原生序列化、fastjson、Log4j 相关链）、PHP（`unserialize`）、Python（`pickle`）。

**典型危害场景**：
- 远程代码执行（RCE）
- 权限提升、数据篡改
- 通过已知「反序列化利用链」触发

**检测与防御**：
- **不要对不可信输入做反序列化**
- 反序列化前做**类型白名单校验**（只允许预期类）
- 优先使用安全的数据格式（JSON + 字段校验）替代原生序列化
- 关注并升级存在反序列化漏洞的组件（如 fastjson、Log4j）

## 四、越权与逻辑漏洞（Broken Access Control / Logic Flaws）

**OWASP 对应**：OWASP Top 10 (2021) A01 访问控制失效。

**原理**：应用**缺少服务端权限校验**或校验不完整，导致用户能访问、操作本不属于自己的资源；逻辑漏洞则是业务流程设计缺陷（如跳过步骤、重复提交、金额/数量篡改、验证码绕过）。

**典型分类**：
- **水平越权**：同权限用户之间访问他人数据（改 userId 参数看别人订单）
- **垂直越权**：低权限用户调用高权限功能（普通用户访问管理接口）
- **逻辑漏洞**：支付金额前端可改、优惠券重复使用、注册/找回密码流程缺陷、验证码不校验服务端

**检测与防御**：
- 权限校验必须落在**服务端**，不能只靠前端隐藏按钮
- 资源访问用**服务端会话身份**定位归属，不接受客户端传入的 userId 作为唯一依据
- 关键业务（支付、下单、改密）加**服务端状态校验 + 幂等控制**
- 测试时覆盖「接口级」越权：用低权限账号直接请求高权限 URL

## 五、总结与 OWASP 对应关系

| 漏洞 | 类别 | OWASP 对应 | 核心防御要点 |
|---|---|---|---|
| SSRF | 服务端请求 | 2021 A10 | URL 白名单 + 禁协议 + IP 复校 + 出站隔离 |
| XXE | XML 解析 | 2017 A4 | 禁用外部实体 / 换 JSON |
| 反序列化 | 数据还原 | 2017 A8 / 2021 A08 | 不反序列化不可信数据 + 类型白名单 |
| 越权 | 访问控制 | 2021 A01 | 服务端权限校验 + 会话身份定位 |
| 逻辑漏洞 | 业务流程 | 2021 A04/A01 | 服务端状态校验 + 幂等控制 |
