# 应急响应基础

> 记录应急响应的标准流程、常见事件类型和取证命令，供面试与实习准备使用。

---

## 一、什么是应急响应

应急响应是在发生安全事件（入侵、勒索、数据泄漏、DDoS 等）后，为**控制影响、定位根因、恢复业务、防止复发**而采取的有序处置过程。目标是「快速止损 + 还原真相 + 闭环整改」。

## 二、应急响应六阶段（PDCERF）

| 阶段 | 英文 | 核心动作 |
|---|---|---|
| 准备 | Preparation | 预案、工具、人员分工、演练 |
| 检测 | Detection | 发现并确认事件（告警 / 日志 / 异常） |
| 遏制 | Containment | 隔离受影响主机、断开网络、改密止损 |
| 根除 | Eradication | 清除恶意程序、漏洞修复、加固 |
| 恢复 | Recovery | 恢复业务、验证可用性 |
| 复盘 | Follow-up | 总结根因、更新预案、输出报告 |

## 三、常见安全事件类型

- **Web 入侵**：网站被挂马、植入后门、拖库
- **勒索软件**：文件被加密、要求赎金
- **账号失陷**：暴力破解 / 钓鱼导致的账号被盗用
- **数据泄漏**：敏感数据外泄（数据库、源码、客户信息）
- **拒绝服务**：DDoS / 资源耗尽
- **内网横向渗透**：单点失陷后内网扩散

## 四、Windows / Linux 取证基础命令

### Linux（取证排查常用）
```bash
# 登录与账号异常
last                      # 登录历史
lastb                     # 失败登录记录
cat /etc/passwd           # 账号列表（检查可疑账号）

# 进程与连接
ps aux                    # 进程列表
netstat -antlp            # 网络连接与进程映射
lsof -i                   # 端口占用

# 自启动与计划任务
crontab -l                # 当前用户计划任务
cat /etc/crontab          # 系统计划任务
ls /etc/init.d/           # 启动脚本

# 文件与痕迹
find / -mtime -1 -type f  # 近 1 天被修改的文件
cat /var/log/auth.log     # 认证日志
```

### Windows（取证排查常用）
```powershell
# 账号与登录
net user                  # 本地账号
query user                # 当前登录会话
Get-WinEvent Security     # 安全日志（登录/审计）

# 进程与服务
tasklist /svc             # 进程与服务
netstat -ano              # 网络连接 + PID
Get-Process | Sort-Object CPU -Descending

# 自启动与计划任务
Get-CimInstance Win32_StartupCommand
schtasks /query /fo LIST /v
```

## 五、事件上报与处置流程

1. **确认事件**：核实告警是否误报，评估影响面与等级
2. **立即上报**：按预案上报安全负责人 / 客户，保留现场
3. **遏制止损**：隔离主机、断网、改密、封禁恶意 IP
4. **取证分析**：日志 + 流量 + 进程 + 文件时间线还原攻击路径
5. **根除修复**：清除后门、修漏洞、补丁加固
6. **恢复验证**：业务恢复 + 复测确认无残留
7. **复盘闭环**：输出应急响应报告，更新预案
