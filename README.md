## 📋 仓库简介

本仓库为厦门软件职业技术学院信息安全技术应用专业在校实训学习存档，记录了基于 LAMP 环境的 DVWA 漏洞演练平台全套安全评估与加固实训、等保 2.0 学习资料、Nmap/Xray/Burp Suite/dirsearch 等安全工具实操笔记与合规辅助 Python 脚本。

所有内容对标企业等保测评、安全交付实施工程师的日常工作文档需求，注重：
- 文档结构化与可读性（贴近安全服务交付报告规范）
- 漏洞原理理解与防御加固并重
- 工具实操步骤可复现
- 严格遵守授权测试边界

## 📁 仓库模块说明

### 1. DVWA 靶场实训（`01-DVWA靶场实训/`）
基于 LAMP 搭建多等级 DVWA 环境，完成 7 类常见 Web 漏洞（暴力破解、SQL 注入、XSS、文件上传、CSRF、命令注入、文件包含）手工复现，包含完整环境部署、漏洞原理、四等级（Low/Medium/High/Impossible）复现、日志审计、风险评估与 8 套系统加固方案，对标企业等保测评、安全实施交付工作流程。

### 2. 等保 2.0 资料合集（`02-等保2.0资料合集/`）
整理等保 2.0 基础理论、标准化资产台账模板、现场巡检记录表、漏洞风险分级判定标准，适配安全厂商售后、等保巡检岗位日常文档工作。

### 3. 安全工具学习笔记（`03-工具使用笔记/`）
整理 Nmap、Xray、Burp Suite、dirsearch、Linux/Windows 服务器运维实操命令，记录日常实训操作步骤，便于快速查阅与复用。

### 4. 合规辅助脚本（`04-合规辅助小脚本/`）
两个简易 Python 工具：Apache/Nginx 日志解析、巡检文档自动生成模板。**仅用于合规日志筛选与文档整理，无漏洞扫描、攻击发包等违规功能**。
