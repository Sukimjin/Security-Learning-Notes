## 仓库简介

本仓库为（院校名称）信息安全技术应用专业在校实训学习存档，记录了基于 LAMP 环境的 DVWA 漏洞演练平台全套安全评估与加固实训、等保 2.0 学习资料、Nmap/Xray/Burp Suite/dirsearch 等安全工具实操笔记与合规辅助 Python 脚本。

所有内容对标企业等保测评、安全交付实施工程师的日常工作文档需求，注重：
- 文档结构化与可读性（贴近安全服务交付报告规范）
- 漏洞原理理解与防御加固并重
- 工具实操步骤可复现
- 严格遵守授权测试边界

## 仓库模块说明

### 1. DVWA 靶场实训（`01-DVWA靶场实训/`）
基于 LAMP 搭建多等级 DVWA 环境，完成 7 类常见 Web 漏洞（暴力破解、SQL 注入、XSS、文件上传、CSRF、命令注入、文件包含）手工复现，包含完整环境部署、漏洞原理、四等级（Low/Medium/High/Impossible）复现、日志审计、风险评估与 8 套系统加固方案，对标企业等保测评、安全实施交付工作流程。

### 2. 等保 2.0 资料合集（`02-等保2.0资料合集/`）
整理 7 份等保 2.0 标准化测评文档（定级备案、资产台账、测评方案、现场巡检、风险分级、整改建议、理论基础），覆盖等保测评全生命周期，适配安全厂商售后、等保巡检岗位日常文档工作。

### 3. 安全工具学习笔记（`03-工具使用笔记/`）
整理 Nmap、Xray、Burp Suite、dirsearch 等安全工具实操，以及 Linux/Windows 服务器运维、MySQL 数据库、Docker 部署、AD 域概念与真实排障案例，便于快速查阅与复用。

### 4. 合规辅助脚本（`04-合规辅助小脚本/`）
三个 Python 工具：Apache/Nginx 日志解析、巡检文档自动生成模板、跨平台系统基线检查。**仅用于合规日志筛选、文档整理与基线巡检，无漏洞扫描、攻击发包等违规功能**。

### 5. 项目交付文档（`05-项目交付文档/`）
面向交付实施岗位的标准化文档：环境部署交付手册（含验收标准）、系统日常运维操作指南（含巡检清单与故障上报流程）、项目交付全流程指南（售前-实施-验收-运维 + 客户沟通话术）。

### 6. 应急响应与流量分析（`07-应急响应与流量分析/`）
面向安服 / 安全运维岗位：应急响应 PDCERF 六阶段与取证命令、Wireshark/tcpdump 流量分析与异常流量识别，配合日志审计做攻击溯源。

## 快速开始

```bash
git clone https://github.com/Sukimjin/Security-Learning-Notes.git
cd Security-Learning-Notes
```

### 一键启动 DVWA 靶场（推荐）

```bash
docker-compose up -d
# 浏览器访问 http://localhost:8080
# 默认账号 admin / password
# 详见 DOCKER_DEPLOY.md
```

### 运行合规辅助脚本

```bash
# 日志分析（仅依赖 Python 标准库，无需安装第三方包）
python3 04-合规辅助小脚本/日志简单解析.py /var/log/apache2/access.log

# 生成巡检报告 Markdown 模板
python3 04-合规辅助小脚本/巡检文档自动生成模板.py --output 巡检报告.md

# 查看完整帮助
python3 04-合规辅助小脚本/日志简单解析.py --help
python3 04-合规辅助小脚本/巡检文档自动生成模板.py --help
python3 04-合规辅助小脚本/系统基线检查.py --help

# 系统基线检查（输出到文件）
python3 04-合规辅助小脚本/系统基线检查.py --output 基线报告.md
```
