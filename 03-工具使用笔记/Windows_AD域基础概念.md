# Windows Active Directory（AD）域基础概念

> 交付实施岗（尤其本地集成商 / 安全服务商）常接触客户 AD 域环境：加域、建 OU、下发组策略、域账号解锁是日常。
> 本文以**概念为主**，配合 [`Windows服务器基础配置.md`](Windows服务器基础配置.md) 中的 PowerShell 实操命令食用更佳。

---

## 一、什么是 AD 域

**Active Directory（AD）** 是 Windows Server 提供的目录服务，用于集中管理网络中的用户、计算机、组、策略等资源。

- **域（Domain）**：一个管理边界，域内资源由同一套目录数据库统一管理。例：`corp.local`
- **域树（Tree）**：多个域首尾相连形成树，共享连续命名空间（如 `corp.local` → `sh.corp.local`）。
- **林（Forest）**：一棵或多棵域树组成的集合，是 AD 的最高边界，共享架构（Schema）与全局编录。
- **信任关系**：域/林之间可建立信任，使一个域的用户能访问另一域资源。

**为什么用域？** 比工作组（Workgroup）分散管理高效：一处建账号、全网信、统一下发策略、集中审计。

---

## 二、角色：DC / 成员服务器 / 工作站

| 角色 | 说明 |
|---|---|
| **域控制器（DC，Domain Controller）** | 运行 AD DS 服务、持有目录数据库与策略的服务器。生产环境至少 2 台做冗余 |
| **成员服务器（Member Server）** | 加入域但不做 DC 的服务器（如文件服务器、Web 服务器） |
| **工作站 / 成员计算机** | 加入域的普通 PC，登录时用域账号 |

**关键**：DC 宕机 → 域登录、策略下发、DNS 都可能受影响。所以生产必做 DC 冗余 + 定期系统状态备份。

---

## 三、OU（组织单位）规划

**OU（Organizational Unit）** 是域内的容器，用于分层管理用户/计算机/组，并**委派权限、链接组策略**。

- 常见规划：`corp.local` → OU`部门` → OU`用户`/`计算机`；或按 `地域\部门` 两级。
- OU 可嵌套，便于"不同部门套不同策略、不同管理员管不同 OU"。
- 与"组（Group）"区别：组用于**授权**（给资源权限），OU 用于**管理与策略分发**。

---

## 四、组策略（GPO）

**GPO（Group Policy Object）** 是集中配置下发机制，可作用于站点 / 域 / OU。

常见下发项：
- 密码策略（长度、复杂度、过期）
- 账户锁定策略（失败几次锁多久）
- 登录脚本、桌面/开始菜单限制
- 软件分发、Windows 更新策略
- 审计策略（谁登录、谁改了什么）

**生效顺序**：本地 → 站点 → 域 → OU（后者覆盖前者）；可用 `gpupdate /force` 强制刷新，`gpresult /r` 看实际生效策略。

---

## 五、对象：用户 / 计算机 / 组

- **用户对象**：域账号，如 `corp\zhangsan`，可登录域内任意加域机器（按权限）。
- **计算机对象**：加域后自动在 AD 中生成，代表该机器身份。
- **组对象**：
  - 安全组（Security Group）：用于授权（分配文件/共享权限）
  - 通讯组（Distribution Group）：用于邮件分发
  - 内置重要组：Domain Admins（域管）、Domain Users（普通域用户）

## 六、域账号常见运维

| 场景 | 操作要点 |
|---|---|
| 账号解锁 | 账号因多次输错被锁，需解锁后让用户重设/重试 |
| 重置密码 | 管理员重置，首次登录强制改密（勾选"用户下次登录须改密码"） |
| 加域 | 在工作站"计算机名"里填域并授权域管账号；加域前确认 DNS 指向 DC |
| 禁用/启用账号 | 离职人员禁用而非删除，保留审计轨迹 |
| 移动 OU | 调整归属部门时移动对象，策略随之变化 |

> 上述操作的 PowerShell 命令（Get-ADUser / Set-ADAccountPassword / Unlock-ADAccount / Add-Computer 等）详见 [`Windows服务器基础配置.md`](Windows服务器基础配置.md) 第 1.2 节，本文不再重复贴命令。

## 七、面试高频追问自检

- 什么是域、域树、林？（见第一节）
- OU 和组有什么区别？（OU 管结构/策略，组管授权）
- 组策略和域策略谁优先？（越靠近对象的 OU 策略覆盖上层）
- 域控宕机怎么办？（冗余 DC + 系统状态备份，用备用 DC 顶上）
- 为什么至少两台 DC？（避免单点故障导致全域登录/策略失效）
