# 项目交付全流程指南（交付实施岗）

> 交付实施岗看重"懂项目节奏、会跟客户打交道"。本文用本仓库的 DVWA 靶场环境交付为实例，串起**售前 → 实施 → 验收 → 运维**四个阶段，并附**客户沟通话术**。
> 配套文档：[`靶场环境部署交付手册.md`](靶场环境部署交付手册.md)（部署+验收）、[`系统日常运维操作指南.md`](系统日常运维操作指南.md)（巡检+故障上报）。

---

## 一、售前阶段：需求确认与环境调研

**目标**：搞清楚"要交付什么、客户环境长啥样"，避免到了现场才发现条件不满足。

- 确认交付范围：交付哪些系统 / 环境（如：LAMP + DVWA 靶场一套）
- 调研客户环境：
  - 操作系统版本（Windows / Linux 发行版）
  - 已有软件（是否装了 Docker / MySQL / Apache）
  - 网络：能否联网拉镜像、端口是否受限、有无隔离网
  - 硬件 / 虚拟机资源（CPU / 内存 / 磁盘）
- 明确边界：哪些你能动、哪些动不了（生产数据、客户账号）

**产出**：环境调研清单 + 交付范围确认（邮件 / 会议纪要留痕）。

---

## 二、实施阶段：部署与风险登记

**目标**：按计划把环境搭起来，过程可控、可追溯。

- 部署方式：本例用 Docker Compose 一键部署（`docker-compose.yml` + [`DOCKER_DEPLOY.md`](../DOCKER_DEPLOY.md)），或手动 LAMP（[`../01-DVWA靶场实训/环境部署文档.md`](../01-DVWA靶场实训/环境部署文档.md)）。
- 分步执行 + 每步验证：装完一个组件就测一个（如 MySQL 能连、Apache 能起、DVWA 能登录）。
- **风险登记**：把遇过的坑记下来，如 8080 端口被占、容器起不来、数据库连不上（详见 [`../01-DVWA靶场实训/环境部署与故障排查手册.md`](../01-DVWA靶场实训/环境部署与故障排查手册.md)）。
- 变更记录：改了什么配置、为什么改，留档防扯皮。

**产出**：部署记录 + 风险台账 + 变更日志。

---

## 三、验收阶段：标准与签字留痕

**目标**：让客户确认"交付物合格"，正式闭环。

- 验收标准模板（示例）：
  | 验收项 | 标准 | 结果 |
  |---|---|---|
  | 服务可达 | DVWA 首页可访问，登录正常 | ✓ / ✗ |
  | 功能正常 | 各漏洞模块 Low~Impossible 可切换 | ✓ / ✗ |
  | 安全配置 | 默认弱口令已改、不必要的端口已关 | ✓ / ✗ |
  | 文档齐全 | 部署手册 + 运维指南已交付 | ✓ / ✗ |
- 双方签字确认，留存验收单（见 [`靶场环境部署交付手册.md`](靶场环境部署交付手册.md) 签字栏）。
- 未完成项列为"待整改"，约定时限，不强行签收。

**产出**：验收报告 + 签字留痕。

---

## 四、运维阶段：交接、巡检与 SLA

**目标**：交付后平稳运行，出问题有流程。

- **交接说明**：向接手的同学/同事讲清怎么启停、怎么看状态、常见问题怎么办（用 [`系统日常运维操作指南.md`](系统日常运维操作指南.md)）。
- **定期巡检**：日 / 周 / 月巡检清单（服务状态、磁盘、日志、备份），异常按等级上报。
- **SLA 概念**：服务级别协议（响应时间 / 解决时间约定）。实习岗先理解概念：P1 紧急几小时响应、P3 普通几天处理。
- **故障上报流程**：发现 → 定级 → 通知对应人 → 处理 → 复盘，避免私自发邮件无跟踪。

**产出**：运维手册 + 巡检记录 + 故障单。

## 五、客户沟通话术（中性、专业、不卑不亢）

### 现场部署常见问答
- 客户："怎么还没好？" → "正在按部署清单推进到 X 步，预计 Y 点完成；当前卡在 Z，我已记录并正在处理。"
- 客户："这个端口为什么开？" → "这是 DVWA Web 服务必需端口，仅监听内网；其他非必要端口已按安全规范关闭。"

### 进度同步话术
- 每日站会 / 群里发："今日完成：A、B；进行中：C（进度 70%）；风险：D，已采取 E 缓解。"

### 问题升级话术
- 超出权限 / 能力："该问题涉及客户生产数据库，我已暂做 X 隔离，建议升级至技术负责人 / 原厂支持协同处理，避免影响业务。"
- 环境不满足："当前客户环境缺 Y 条件（如无法联网拉镜像），需协调 Z 资源，否则将影响交付时间，请帮忙推动。"

### 边界守住
- 不动客户生产数据、不索要无关账号密码；
- 不确定先确认再动，宁慢勿错；
- 所有关键沟通留邮件 / 工单记录。
