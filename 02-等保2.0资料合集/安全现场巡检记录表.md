# 安全现场巡检记录表

> 适用范围：等保 2.0 测评现场操作、安全运维日常巡检
> 使用场景：驻场工程师、客户运维人员、测评机构

---

## 一、巡检说明

### 1.1 巡检目的

- 验证安全设备 / 系统的运行状态
- 核查安全策略、配置与基线的符合度
- 发现潜在的安全隐患与配置缺陷
- 留存巡检证据，满足等保合规要求

### 1.2 巡检频率

| 类型 | 频率 | 责任人 |
|---|---|---|
| 日巡检 | 每个工作日 | 运维值班员 |
| 周巡检 | 每周一 | 运维主管 |
| 月度巡检 | 每月 1 号 | 运维主管 + 安全员 |
| 季度巡检 | 每季度首月 | 部门负责人 |
| 年度巡检 | 每年 1 月 | 部门负责人 + 测评机构 |

### 1.3 巡检方法

- **现场查看**：登录设备查看状态、日志
- **远程连接**：通过堡垒机远程操作
- **访谈**：与运维人员面谈确认流程
- **抽样**：对关键设备/账号进行抽查

## 七、附录：常见问题对照表

### 7.1 Linux 常见高危问题
- PermitRootLogin yes → 应改为 no
- PasswordAuthentication yes 且无 MFA → 风险高
- 防火墙关闭 → 必须启用
- 大量失败登录 → 可能被爆破

### 7.2 网络设备常见高危问题
- 存在 `any any any permit` → 立即整改
- 远程管理仅 Telnet → 必须 SSH
- 无 ACL 或过于宽松 → 收紧
- NTP 未同步 → 故障排查 / 日志分析受阻

### 7.3 数据库常见高危问题
- root 远程可登 → 必须禁用
- 匿名账号存在 → 必须清理
- 弱口令 → 必须重置
- 无审计日志 → 必须开启 general_log

### 7.4 Web 应用常见高危问题
- 上传目录可执行 PHP → 立即禁用
- 信息泄露（目录列表、版本号）→ 关闭
- HTTPS 证书过期 → 立即更新
- 备份文件残留 → 删除
