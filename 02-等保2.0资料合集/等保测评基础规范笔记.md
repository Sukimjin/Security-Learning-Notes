# 等保 2.0 测评基础规范笔记

> 适用对象：等保测评工程师、安全服务工程师、运维人员
> 参考标准：GB/T 22239-2019《信息安全技术 网络安全等级保护基本要求》

---

## 一、等保 2.0 概述

### 1.1 等保 2.0 与 1.0 的区别

| 维度 | 等保 1.0 | 等保 2.0 |
|---|---|---|
| 标准体系 | 2008 版 | 2019 版 |
| 监管要求 | 被动 | 主动防御 |
| 核心思想 | 防御 | 全面 + 重点 |
| 安全目标 | 保密性 | 保密性 + 完整性 + 可用性 |
| 法律地位 | 推荐 | 强制（网络安全法） |
| 扩展要求 | 无 | 云计算 / 移动互联 / 物联网 / 工业控制 |
| 定级标准 | 自主 | 自主 + 监督审核 |

### 1.2 法律依据

- **《网络安全法》（2017-06-01 实施）**：第二十一条明确要求网络运营者按等保制度履行安全保护义务
- **《数据安全法》（2021-09-01 实施）**：数据分级分类保护
- **《关键信息基础设施安全保护条例》（2021-09-01 实施）**：关基设施特殊保护
- **《个人信息保护法》（2021-11-01 实施）**：个人信息保护要求

## 二、等保 2.0 五个级别

### 2.1 等级划分

| 等级 | 适用对象 | 监管要求 |
|---|---|---|
| **第一级** | 一般系统 | 用户自主保护 |
| **第二级** | 一般业务系统 | 指导保护（等保 1.0 旧称） |
| **第三级** | 重要信息系统 | 监督检查（旧称「等保三级」） |
| **第四级** | 关键信息基础设施 | 强制保护 |
| **第五级** | 涉密系统 | 专控保护（涉密行业使用） |

### 2.2 常见行业定级

| 行业 | 常见级别 | 说明 |
|---|---|---|
| 政府门户 | 三级 | 公众服务 |
| 金融核心 | 四级 | 关基设施 |
| 医疗机构 | 三级 | 患者数据 |
| 教育系统 | 二级 | 内部使用 |
| 一般企业官网 | 二级 | 公众服务 |
| 关基设施 | 四级 | 强制要求 |

## 三、五个安全层面

等保 2.0 五个安全控制层面：

### 3.1 物理和环境安全

| 控制点 | 三级要求 |
|---|---|
| 物理位置选择 | 机房选址应避开地震、水灾、火灾等 |
| 物理访问控制 | 出入登记、门禁系统、监控 |
| 防盗窃和防破坏 | 设备固定、监控告警 |
| 防雷击 | 接地防雷 |
| 防火 | 自动报警 + 气体灭火 |
| 防水和防潮 | 防水检测 + 除湿设备 |
| 防静电 | 防静电地板 + 接地 |
| 温湿度控制 | 温度 18-27℃，湿度 40%-60% |
| 电力供应 | UPS + 备用发电机 |
| 电磁防护 | 电磁屏蔽 |

| 可信验证 | 通信双方可信验证 |
| 边界防护 | 边界访问控制、恶意代码防范 |
| 访问控制 | 最小权限、ACL |
| 入侵防范 | IDS/IPS、流量监控 |
| 恶意代码防范 | 防病毒、APT 检测 |
| 安全审计 | 日志审计、行为审计 |

## 五、测评流程

### 5.1 测评阶段

```
1. 测评准备
   ├── 测评合同签订
   ├── 测评方案制定
   └── 工具准备

2. 方案编制
   ├── 资产识别
   ├── 威胁识别
   ├── 脆弱性识别
   └── 风险分析

3. 现场测评
   ├── 访谈（与运维、开发、管理人员）
   ├── 文档审查（管理制度、运维记录）
   ├── 配置检查（设备配置核查）
   ├── 工具测试（漏洞扫描、渗透测试）

4. 报告编制
   ├── 单元测评结果
   ├── 整体测评
   ├── 风险分析
   └── 等级测评结论

5. 备案与整改
   ├── 测评报告提交公安机关
   └── 客户按报告整改
```

### 5.2 测评结论判定

| 综合得分 | 测评结论 | 含义 |
|---|---|---|
| ≥ 70 分 | **优** | 无高危项，符合要求 |
| ≥ 60 分且 < 70 分 | **良** | 有少量中危项，限期整改 |
| < 60 分 | **差** | 不符合要求，需重新测评 |

### 5.3 关键控制点（高风险项）

以下为测评中**最容易不符合**的控制点：

1. **物理访问控制**：机房未实施双人进出、无门禁记录
2. **网络安全审计**：未配置日志审计或未集中管理
3. **边界完整性检查**：无法限制非授权设备接入内网
4. **入侵防范**：未部署 IDS/IPS 或规则未更新
5. **身份鉴别**：无 MFA、密码策略弱
6. **访问控制**：权限过松、特权账号泛滥
7. **恶意代码防范**：未集中管理防病毒
8. **数据保密性**：敏感数据明文存储
9. **备份与恢复**：无备份或未演练
10. **应急预案**：无应急预案或未演练
