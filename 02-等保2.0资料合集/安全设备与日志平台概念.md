# 安全设备与日志平台概念

> 安服 / SOC 岗面试常问："防火墙和 WAF 区别？""IDS 和 IPS 区别？""你了解 SIEM / 日志平台吗？"
> 本文以**概念 + 对比**为主，帮你在被追问时有体系地答出来，不要求会配设备。

---

## 一、防火墙 / IDS / IPS / WAF 四者对比

| 设备 | 工作位置 | 核心能力 | 动作 | 类比 |
|---|---|---|---|---|
| **防火墙（Firewall）** | 网络层 / 传输层（三层/四层） | 基于 IP / 端口 / 协议的访问控制 | 允许 / 拒绝 | 小区门卫（看谁进门） |
| **IDS（入侵检测）** | 旁路监听 | 检测攻击特征，报警 | 只告警不拦截 | 监控摄像头（看到坏人喊） |
| **IPS（入侵防御）** | 串联部署 | 检测 + 实时阻断 | 告警 + 阻断 | 安检门（发现危险品直接拦） |
| **WAF（Web 应用防火墙）** | 应用层（七层，护 Web） | 防 SQL 注入 / XSS / 上传等 Web 攻击 | 允许 / 拦截 | 银行柜台防抢（专防针对业务的手段） |

**关键区别**：
- 防火墙管"谁能通信"，WAF 管"Web 请求里有没有恶意 payload"——WAF 看得懂 HTTP，防火墙看不懂。
- IDS 旁路"看但不拦"，IPS 串联"看了就拦"；IPS 误拦会影响业务，故规则需调优。
- 四者互补：防火墙做边界访问控制，IPS 拦已知攻击，WAF 护 Web 应用，IDS 留痕审计。

## 二、与等保"安全区域边界"的对应

等保 2.0 把安全防护分成**安全物理环境 / 安全通信网络 / 安全区域边界 / 安全计算环境 / 安全管理中心**等。

- **安全区域边界**主要靠：防火墙（边界访问控制）、IDS/IPS（边界入侵防范）、WAF（Web 边界应用层防护）。
- **安全通信网络**靠：VPN、通信加密（TLS）。
- **安全管理中心**靠：集中审计 + 日志平台（见下一节）。

所以面试答"等保怎么落地边界防护"，可以说：边界部署防火墙做访问控制、IPS 串接入侵拦截、对外 Web 前置 WAF，日志统一送 SIEM 留存审计。

## 三、日志平台概念：SIEM / ELK / Splunk

### 为什么集中日志？
单台设备日志散落各处，出问题难关联、难追溯。集中日志平台把各设备/系统日志收拢，做**检索、关联、告警、可视化**，是安全运营（SOC）的基础。

### 几个名词

| 名词 | 是什么 | 典型用途 |
|---|---|---|
| **SIEM** | 安全信息和事件管理（Security Information & Event Management） | 汇总日志 + 关联分析 + 实时告警，发现异常攻击链 |
| **ELK** | Elasticsearch + Logstash + Kibana 开源套件 | Logstash 采集清洗、ES 存储检索、Kibana 可视化 dashboards |
| **Splunk** | 商业日志分析平台 | 企业级日志检索、监控、告警，功能强但按数据量 licensing |

**三者关系**：SIEM 是"能力定位"（集中分析告警），ELK / Splunk 是实现该能力的"具体平台"。很多 SIEM 底层就用 ELK 或 Splunk 存日志。

### 学生能做的轻量实践
不用搭整套 ELK，也能体现"日志结构化思维"——本仓库 [`../04-合规辅助小脚本/日志简单解析.py`](../04-合规辅助小脚本/日志简单解析.py) 就是一个示例：用 Python 标准库把 Apache/Nginx 访问日志解析成结构化字段（IP、时间、请求、状态码、UA），再统计异常模式。这正是 SIEM "日志解析 + 模式识别" 的极简版思路。
