4. **整改指导**：提出可落地的整改建议

## 三、测评内容与方法

### 3.1 测评层面覆盖

等保 2.0 第三级测评涵盖 **10 个层面**：

| 类别 | 层面 | 测评项数（参考） |
|------|------|:---:|
| **技术** | 1. 安全物理环境 | ~10 项 |
| | 2. 安全通信网络 | ~8 项 |
| | 3. 安全区域边界 | ~10 项 |
| | 4. 安全计算环境 | ~26 项 |
| | 5. 安全管理中心 | ~6 项 |
| **管理** | 6. 安全管理制度 | ~7 项 |
| | 7. 安全管理机构 | ~7 项 |
| | 8. 安全管理人员 | ~7 项 |
| | 9. 安全建设管理 | ~24 项 |
| | 10. 安全运维管理 | ~22 项 |

> 总计约 127 个测评项（第三级），具体以 GB/T 28448-2019 为准。

### 3.2 测评方法

| 方法 | 说明 | 适用场景 |
|------|------|---------|
| **访谈** | 与运维/管理/开发人员面对面交流 | 管理制度落实、运维流程确认 |
| **文档审查** | 审查管理制度、配置文件、日志记录 | 制度合规性、记录完整性 |
| **配置检查** | 登录设备查看配置命令 | 网络设备、服务器、数据库基线 |
| **工具测试** | 使用扫描/渗透工具验证 | 漏洞扫描、渗透测试、协议分析 |
| **现场查看** | 物理环境实地查看 | 机房、门禁、消防、监控 |

### 3.3 测评工具

| 类别 | 工具 | 用途 | 合规说明 |
|------|------|------|---------|
| 漏洞扫描 | 绿盟远程安全评估系统 | 主机/网络漏洞扫描 | 已授权使用 |
| Web 扫描 | Nmap + 手工验证 | 端口/服务识别 | 仅授权范围 |
| 配置核查 | 基线脚本 + 人工核查 | 系统基线合规检查 | 只读操作 |
| 流量分析 | tcpdump / Wireshark | 网络流量分析 | 已授权抓包 |
| 渗透测试 | 手工测试（无自动化攻击） | 验证漏洞可利用性 | 仅验证不利用 |

> 注意 测评工具仅用于安全评估，不包含攻击性工具（如 webshell、EXP），不执行破坏性操作。

### 3.4 测评工作单元

#### 单元 1：安全物理环境

| 测评项 | 测评方法 | 判定标准 |
|--------|---------|---------|
| 物理访问控制 | 现场查看门禁、登记记录 | 出入登记完整、门禁系统正常 |
| 防火防水 | 查看消防设施、防水措施 | 自动报警 + 气体灭火、防水检测 |
| 温湿度控制 | 查看温湿度计、空调系统 | 温度 18-27℃，湿度 40%-60% |
| 电力供应 | 查看 UPS、备用电源 | UPS 满足断电后持续供电 ≥ 4h |
| 电磁防护 | 查看电磁屏蔽措施 | 机房电磁屏蔽合格 |

#### 单元 2：安全通信网络

| 测评项 | 测评方法 | 判定标准 |
|--------|---------|---------|
| 网络架构 | 查看拓扑图、VLAN 配置 | 分区隔离（DMZ/内网/办公） |
| 通信传输 | 检查加密协议配置 | HTTPS/SSH 加密传输 |
| 可信验证 | 查看设备可信验证功能 | 通信双方可信验证已启用 |
| 边界防护 | 查看防火墙规则 | 无 any-any-permit 规则 |

#### 单元 3：安全计算环境

| 测评项 | 测评方法 | 判定标准 |
|--------|---------|---------|
| 身份鉴别 | 检查密码策略、MFA 配置 | 密码 ≥ 8 位、复杂度策略、MFA |
| 访问控制 | 检查用户权限分配 | RBAC、最小权限、无多余管理员 |
| 安全审计 | 检查日志审计配置 | 审计日志已开启、留存 ≥ 6 个月 |
| 入侵防范 | 检查 IDS/IPS、EDR 部署 | 已部署且规则更新 |
| 恶意代码防范 | 检查防病毒部署 | 已部署且病毒库最新 |
| 数据保密性 | 检查敏感数据加密存储 | 敏感字段加密存储 |
| 数据备份恢复 | 检查备份策略与恢复演练 | 每日备份 + 季度恢复演练 |

#### 单元 4：安全管理中心

| 测评项 | 测评方法 | 判定标准 |
|--------|---------|---------|
| 系统管理 | 查看集中管理平台 | 统一配置、统一监控 |
| 审计管理 | 查看日志审计平台 | 集中收集、关联分析 |
| 安全管理 | 查看 SOC/态势感知 | 集中告警、统一响应 |
| 集中管控 | 查看运维通道 | 通过堡垒机统一运维 |

## 四、测评计划

### 4.1 测评阶段划分

| 阶段 | 工作内容 | 周期 | 产出 |
|------|---------|------|------|
| **阶段一：测评准备** | 项目启动、资料收集、资产确认 | 1-3 天 | 测评方案、资产清单确认 |
| **阶段二：方案编制** | 编制测评方案、确定测评项 | 2-3 天 | 测评方案（本文档） |
| **阶段三：现场测评** | 访谈、配置检查、工具测试 | 3-5 天 | 现场测评记录 |
| **阶段四：分析评价** | 结果汇总、风险分析、等级判定 | 2-3 天 | 问题汇总表、风险分析 |
| **阶段五：报告编制** | 编制测评报告 | 2-3 天 | 测评报告（正式） |
| **阶段六：结果确认** | 客户确认、整改建议 | 1-2 天 | 测评报告（终版） |

### 4.2 里程碑计划

```
Day 1-3:   测评准备（资料收集、资产确认）

Day 12-14: 分析评价（结果汇总、风险判定）
Day 15-17: 报告编制
```

## 五、测评风险控制

### 5.1 测评风险识别

| 风险类型 | 风险描述 | 控制措施 |
|---------|---------|---------|
| **业务中断** | 工具测试可能导致业务系统异常 | 测试前备份数据、避开业务高峰、准备回退方案 |
| **数据泄露** | 测评过程接触敏感数据 | 签署保密协议、数据脱敏处理、测评结束后清理 |
| **误操作** | 配置检查时误改配置 | 只读操作为主、变更操作需审批 |
| **工具风险** | 扫描工具对系统造成压力 | 限速扫描、非业务时段执行 |

### 5.2 测评安全承诺

1. 测评团队签署保密协议，不泄露客户信息
2. 测评过程中不执行任何破坏性操作
3. 测评结果仅用于等级保护合规评估
4. 测评数据在项目结束后按要求销毁

## 七、测评结论判定标准

### 7.1 单项判定

| 判定结果 | 含义 |
|---------|------|
| **符合** | 完全满足测评项要求 |
| **部分符合** | 基本满足但有少量差距 |
| **不符合** | 未满足测评项要求 |
| **不适用** | 该测评项不适用于本系统 |

### 7.2 综合判定

| 综合得分 | 结论 | 含义 |
|---------|------|------|
| ≥ 90 分 | **优** | 无高危不符合项 |
| 70-89 分 | **良** | 有少量中低危不符合项 |
| 60-69 分 | **中** | 有中危不符合项，需整改 |
| < 60 分 | **差** | 有高危不符合项，需重新测评 |

### 7.3 高危一票否决项

以下任一不符合项将直接判定为「差」：
- 无网络安全审计
- 无身份鉴别（弱口令/默认密码）
- 无数据备份
- 无应急预案
- 无安全管理制度
