## 一、资产台账说明

### 1.1 资产定义

资产 = 客户单位具有价值的任何事物。等保 2.0 将资产分为 5 类：
- **数据**（数据库、文件、文档）
- **软件**（操作系统、应用软件、源代码）
- **硬件**（服务器、网络设备、安全设备）
- **服务**（网络服务、业务服务）
- **人员**（运维人员、开发人员、外部人员）

### 1.2 台账维护原则

- **完整性**：覆盖客户所有 IT 资产，无遗漏
- **准确性**：信息真实、定期更新
- **时效性**：资产变化（新增/下线/变更）及时更新
- **保密性**：台账本身需保密（包含网络拓扑、IP 等敏感信息）

### 1.3 更新频率

| 资产类型 | 更新频率 |
|---|---|
| 核心业务系统 | 每月更新 |
| 服务器、网络设备 | 每季度更新 |
| 一般终端 | 每年更新 |
| 临时资产（项目测试） | 项目结束即更新 |

## 二、资产台账字段说明

| 字段 | 含义 | 必填 |
|---|---|---|
| 资产编号 | 唯一标识（如 SRV-2026-001） | 是 |
| 资产名称 | 设备/系统名称 | 是 |
| 资产类型 | 服务器/网络设备/应用系统/数据库等 | 是 |
| 品牌型号 | 硬件品牌型号 / 软件版本 | 是 |
| 操作系统 | 安装的操作系统 | 是 |
| 部署位置 | 物理位置 / 云上区域 | 是 |
| IP 地址 | IPv4 地址（公网/内网） | 是 |
| MAC 地址 | 网卡 MAC | 否 |
| 业务用途 | 承载业务 | 是 |
| 责任部门 | 业务归口部门 | 是 |
| 责任人 | 直接责任人（姓名 + 联系方式） | 是 |
| 安全等级 | 等保等级（二/三/四级） | 是 |
| 重要程度 | 核心 / 重要 / 一般 | 是 |
| 上线时间 | 首次上线日期 | 是 |
| 维护方 | 自维 / 第三方运维 | 是 |
| 备注 | 其他需要说明的事项 | 否 |

## 十、台账模板使用说明

1. **新建项目**：复制本模板，按客户实际填写
2. **定期更新**：每季度对资产台账进行核对、增删
3. **保密管理**：本台账含敏感信息，应按机密文档管理
4. **存放位置**：客户内网服务器 + 加密备份
5. **借阅审批**：台账调阅需部门负责人审批
