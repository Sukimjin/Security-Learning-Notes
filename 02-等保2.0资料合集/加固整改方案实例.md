## 三、整改措施详情（基础设施）

### H-001：SSH 允许 root 密码登录

| 项目 | 内容 |
|---|---|
| 问题描述 | `/etc/ssh/sshd_config` 中 `PermitRootLogin yes` |
| 风险分析 | root 可被远程密码爆破，一旦得手即获最高权限 |
| 整改措施 | 1. `PermitRootLogin no` 2. 新建 sudo 普通用户 `lin_ops` 3. 密钥登录替代密码 |
| 验证方法 | `grep PermitRootLogin /etc/ssh/sshd_config` 为 `no`；root 密码登录被拒 |
| 结果 | 已整改并通过验证（2026-08-16） |

### M-001：系统包待更新

| 项目 | 内容 |
|---|---|
| 问题描述 | 12 个可升级包，含 2 个安全更新 |
| 整改措施 | 维护窗口执行 `apt update && apt upgrade -y`，重启后核实 |
| 验证方法 | `apt list --upgradable` 无安全更新残留 |
| 结果 | 已整改并通过验证（2026-08-18） |

### L-001：Apache 未隐藏版本信息

| 项目 | 内容 |
|---|---|
| 整改措施 | `apache2.conf` 设 `ServerTokens Prod` + `ServerSignature Off`，重载服务 |
| 验证方法 | `curl -I http://192.168.56.101` 响应头不含 Apache 版本 |
| 结果 | 已整改并通过验证（2026-08-20） |
